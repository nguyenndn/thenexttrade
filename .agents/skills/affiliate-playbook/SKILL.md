# Affiliate Marketing Playbook (SOPs)

When the user requests help with affiliate marketing, apply the following rules and frameworks instead of writing content based on instinct:

## 1. Product Evaluation (5-Dimension Framework)
When the user asks to evaluate or choose an affiliate program, use this scoring system (Total 100%):
- **Income Potential (30%)**: Is the commission % high? Is it one-time or recurring? Is the product price high?
- **Content Potential (25%)**: Is the product easy to demo/screenshot/record? Is there a free trial to use for writing reviews? Are there multiple angles to write about?
- **Market Demand (20%)**: Is the search volume good? Is the trend going up or down?
- **Competition Level (15%)**: Are there already too many big players promoting this in the niche? Fewer competitors = higher score.
- **Reliability (10%)**: Is the company reputable? How are the real reviews on G2/Trustpilot?
-> **Decision**: Score > 7.5/10: "Worth investing". From 5.5 - 7.4: "Worth trying". Under 5.5: "Skip".

## 2. FTC Compliance Check (MANDATORY)
**Before publishing any article/landing page containing an affiliate link, you must check:**
- **Presence of Disclosure**: It must include a statement like "This post contains affiliate links, I may earn a commission if you purchase..."
- **Placement**: It must be placed at the TOP of the article, before the first affiliate link appears. Do not hide it in the footer.
- **Transparency**: Clearly state "affiliate link", do not use ambiguous terms.
- **Link Attributes**: The HTML code of the affiliate link must have `rel="nofollow sponsored"` and `target="_blank"`.
- **Prohibited Claims**: Absolutely no income guarantees, no earnings promises, and no fake scarcity (fake timers).

## 3. Social Media Writing Rules for Affiliate
Never post the exact same content across all platforms. Adhere to the rules of each platform:
- **LinkedIn**: 
  - DO NOT start with "I am excited/proud to share..."
  - Share using the formula: STORY (or contrarian view) -> DATA -> LIGHT CALL TO ACTION.
  - **ABSOLUTELY NO affiliate links in the main post** (the algorithm will suppress engagement). Tell the user: "I'll leave the link in the comments".
- **Twitter (X)**:
  - Write in the form of a Thread (5-7 tweets).
  - Structure: Tweet 1 (Curiosity Hook) -> Tweet 2-5 (Detailed Problem & Solution) -> Tweet 6 (Social Proof) -> Tweet 7 (Call to Action + #ad tag).
- **Reddit**:
  - The community strongly dislikes ads. You must share real experiences (what you did, what the results were).
  - MANDATORY to list both actual PROS and CONS.
  - At the end of the post, clearly state: "Full disclosure: This post contains affiliate links".

## 4. Content Repurposing
When you have a 1,500-word Blog Review, don't let it go to waste. Propose to the user to "break it down" into the following matrix:
- 5 Short posts (for Facebook/LinkedIn).
- 1 Twitter Thread analyzing one specific feature deeply.
- 1 Authentic Reddit post (focusing on a Case Study of using the product).
- 2 Email snippets (Used for Email Drip Sequence to nurture customers).
- 1 Short Video script (TikTok/Reels) of 60s (3s Hook -> Problem -> Show Solution -> CTA).

> **Always act with a System mindset rather than just being a content writing machine.** All content created must fit into a clear Funnel.
